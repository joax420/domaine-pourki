# Domaine Pourki — Website

Official landing page for **Domaine Pourki**, a nature destination located along the Richelieu River in Québec. The site showcases activities, accommodations, and booking options for individuals, couples, families, and groups.

## Overview

This is a custom-built static website designed to promote Domaine Pourki’s offerings, including:

- Beach and pool access  
- Chalets and lodging  
- Water activities (canoe, paddle, etc.)  
- Cycling and group activities  
- Business and event hosting  

The site is fully responsive and supports both French and English.

## Features

- Responsive design (mobile-first, optimized layouts)
- Language switcher (FR / EN toggle)
- Video sections for visual promotion
- Audience targeting (couple/family vs group/club)
- Structured SEO metadata (Open Graph, JSON-LD schema)
- Modern UI with smooth scrolling and animations
- Custom branding and styling

## Tech Stack

- HTML5  
- CSS3 (custom, no frameworks)  
- Vanilla JavaScript (for interactions like language toggle)  
- Google Fonts (Playfair Display, Jost)

## SEO & Metadata

The site includes:

- Meta descriptions and social previews (Open Graph + Twitter)
- Structured data using Schema.org:
  - WebPage
  - TouristAttraction
  - LodgingBusiness

## Usage

1. Clone or download the repository  
2. Open index.html in a browser  
3. Deploy using:
   - GitHub Pages  
   - Netlify  
   - Any static hosting  

## Customization

You can easily modify:

- Text content via data-fr / data-en attributes  
- Images in the /images folder  
- Videos in the <video> sections  
- Colors and layout via the CSS in <style>
